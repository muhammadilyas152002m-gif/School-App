School Management System – source update (13 Nov 2026)

Changes made in this update
1. Added the supplied school logo to assets/school_management_launcher.png.
2. Added flutter_launcher_icons configuration and a GitHub Actions step to generate the Android launcher icon.
3. Updated the DMC PDF header to show the school logo and the student's registration photo (when the photo file is available on the device that generates the PDF).
4. Fixed StockManagementPage to refresh its displayed stock/issue lists when its parent supplies updated records. The existing Add/Edit/Delete/Issue controls remain in place.

Important limitations – not yet completed
- This source has not been built or tested with Flutter in this environment.
- Student photos are still saved as local file paths. They are not uploaded to Firebase Storage, so a photo may not be available when another phone generates a DMC.
- Firestore rules still authorize school data using the principal/owner account only. Staff accounts are still stored in local SharedPreferences and are not Firebase-authenticated users. Cross-phone staff login and secure View/Add/Edit/Delete permission enforcement are NOT implemented.
- The app still uses SharedPreferences as local storage/cache and writes cloud data as school-scoped Firestore documents when a principal is signed in. This update does not remove local storage or make the app online-only.
- Student ID cards and fee slips have not yet been redesigned into four-per-page and five-per-page A4 print layouts. The DMC now has a more polished header, but a complete animated 3D preview/design system is not included.
- The launcher icon is generated by the GitHub Actions workflow. The icon will only appear in the APK after the workflow succeeds and the newly built APK is installed.

Do not change the Play Store upload signing key unless you have verified it matches the upload key registered in Play Console.
